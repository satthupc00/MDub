Bắt đầu với MDub — 3 bước, làm 1 lần

1Tải giọng đọc
Model Kokoro tiếng Việt + 14 giọng (~90 MB). Chạy offline, miễn phí.
2Nhập API key Claude
Dùng để dịch phụ đề. Lấy key ở console.anthropic.com → API Keys.
3Cài extension Chrome
  1. Bấm Mở trang extension và bật Developer mode (góc phải trên).
  2. Bấm Load unpacked rồi chọn thư mục extension (bấm Copy đường dẫn rồi dán vào ô địa chỉ).
  3. Mở một video YouTube có phụ đề tiếng Anh, bấm nút VI trên thanh điều khiển video.
